# Agent Factory Backlog Index

This directory points to the live Agent Factory Excel backlog.

## Backlog files

- `../data/backlog/agent_factory_backlog.xlsx` - active backlog source of truth.
- The workbook combines the current roadmap gaps and latest diagram/workflow issues.

## Rules for future agents

1. Add new work here.
2. Keep backlog items small enough for one bounded coding session unless explicitly marked as an epic.
3. Each item must include acceptance criteria.
4. Diagram work must include source, rendered preview, and linked documentation.
5. Expensive, destructive, ambiguous, or broad discovery work must request human approval before execution.
